GPT model for web search in Chat Completions

GPT-4o Search Preview is a specialized model trained to understand and execute [web search](https://developers.openai.com/api/docs/guides/tools-web-search?api-mode=chat) queries with the Chat Completions API. In addition to token fees, web search queries have a fee per tool call. Learn more in the [pricing](https://developers.openai.com/api/docs/pricing) page.
