# GPT-Live 1

- Model ID: gpt-live-1
- Model type: other
- Current snapshot: gpt-live-1

Our premier model for natural, expressive voice conversations with smooth interruption handling.

GPT-Live 1 is a full-duplex voice model for real-time conversations. It can listen and speak at the same time, and delegate reasoning and tool use to a backend agent.

Learn how to [get started with GPT-Live](https://developers.openai.com/api/docs/guides/live), [configure delegation](https://developers.openai.com/api/docs/guides/live-delegation), and [prompt the model](https://developers.openai.com/api/docs/guides/live-prompting).
