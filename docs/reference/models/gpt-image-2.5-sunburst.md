# GPT-Image-2.5 Sunburst

- Model ID: gpt-image-2.5-sunburst
- Model type: other
- Current snapshot: gpt-image-2.5-sunburst-2026-09-08

Our most capable model for image generation and editing

GPT Image 2.5 Sunburst generates and edits images from text and image inputs. Use it for workflows where editing precision matters most. It supports `low`, `medium`, `high`, `xhigh`, `max`, and `auto` quality settings. Select it directly in the Image API or as the model of the Responses API image generation tool. Learn more in the [image generation guide](https://developers.openai.com/api/docs/guides/image-generation).
